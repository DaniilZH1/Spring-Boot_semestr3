# Spring Boot Lab 8 — Spring Security

Веб-приложение управления студентами с регистрацией и входом через Spring Security.

## Запуск

Запустите `MySpringBoot2DbaseApplication` из IntelliJ IDEA

## Работа с приложением

1. Откройте `http://localhost:8083/` и зарегистрируйтесь через `/register`.
2. Войдите на `/login`, указав адрес электронной почты и пароль.
3. После входа доступны список студентов (`/list`), учебные группы (`/groups`) и пользователи (`/users`).

Пароли хранятся в базе в BCrypt-хеше. Hibernate создаёт таблицы `USERS`, `ROLES` и `USER_ROLES`, а также сохраняет существующие таблицы приложения.
